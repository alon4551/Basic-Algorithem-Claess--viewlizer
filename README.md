# סטודיו ומפרש יסודות מדעי המחשב ב-C# ו-Java 💻
## אלון שרייבמן — מורה פרטי
### כלי הוראה, המחשה ויזואלית ודיבאגר אינטראקטיבי ליסודות מדעי המחשב

מערכת אינטראקטיבית עצמאית (Offline-first) להמחשה והרצה צעד-אחר-צעד של אלגוריתמים, מערכים, מטריצות, מחרוזות, פונקציות ומחלקות בשפת C#, המותאמת לתוכנית הלימודים ולבחינות הבגרות של משרד החינוך.

---

## 🌟 יכולות מרכזיות

1. **מערכים חד-ממדיים (1D Arrays) ומצביעים**:
   - הדמיית תאי מערך עם אינדקסים `[0..N-1]`.
   - הצגת מצביעי לולאות ומעקב בזמן אמת (`i`, `j`, `min`, `max`, `left`, `right`).
   - זיהוי והתראה על חריגה מגבולות המערך (`IndexOutOfRangeException`).

2. **מטריצות ורשתות דו-ממדיות (2D Matrices)**:
   - רשת תאים אינטראקטיבית עם אינדקסי שורות ועמודות `[row, col]`.
   - תמיכה מלאה בתחביר `int[,]` ופונקציות `GetLength(0)` ו-`GetLength(1)`.
   - הדגשת אלכסון ראשי ואלכסון משני, תא פעיל, וסריקות שורה/עמודה.

3. **מחרוזות ותווים (Strings & Chars)**:
   - פריסת מחרוזת לתאי תווים עם אינדקסים.
   - הדגמת מתודות מחרוזת: `Length`, `Substring`, `IndexOf`, `Contains`, `ToUpper`, `ToLower`, `Replace`.
   - פונקציות בדיקת תווים: `char.IsDigit`, `char.IsLetter`.

4. **פונקציות ומחלקת Math**:
   - מעקב אחר קריאות לפונקציות ומחסנית קריאות (Call Stack).
   - פעולות שלמים: הבדל בין חילוק שלם `/` לשארית מודולו `%` (פירוק מספר לספרות).
   - מתודות `Math.Max`, `Math.Min`, `Math.Abs`, `Math.Pow`, `Math.Sqrt`.

5. **מחלקות ועצמים בסיסיים (OOP & Heap)**:
   - הדמיית מופעי עצמים בזיכרון הערימה (Heap) עם מזהי הפניה ושדות.
   - תמיכה בלשוניות קבצים מרובות (`Program.cs` + `Student.cs` / `Point.cs`).
   - מערך של עצמים (`Student[]`).

6. **מחולל טבלת מעקב (Dry Run / Trace Table) בסטנדרט בגרות**:
   - יצירת טבלת מעקב אוטומטית מלאה עם עמודות דינמיות למשתנים, תנאים ופלט.
   - **קפיצה בזמן (Time-Travel)**: לחיצה על כל שורה בטבלה מעבירה את התצוגה לאותו שלב בדיוק.
   - כפתור העתקת הטבלה בפורמט Markdown ללוח (Clipboard) עבור שיעורי בית ומבחנים.

7. **עורך קוד עם השלמה אוטומטית ואבחון פדגוגי בעברית**:
   - Snippets מהירים ללולאות `for`, מטריצות מקוננות, מערכים, `Console.WriteLine`.
   - הסברים ברורים בעברית לשגיאות ריצה (לולאה אינסופית, חלוקה באפס, חריגה מאינדקס).

---

## 🚀 הפעלה מהירה

המערכת כתובה ב-Vanilla JavaScript (ES6+), HTML5 ו-CSS3 בלבד, ואינה דורשת התקנה או חיבור לאינטרנט:
- פתח את הקובץ `index.html` בכל דפדפן מודרני (Chrome, Edge, Firefox).
- ניתן להעלות את התיקייה ל-GitHub Pages לקבלת אתר חי בחינם.
